# Wayon – 100 Start-URLs für einen ersten Crawl
#
# Ausgewählt nach Inhalt und Crawlbarkeit (viel Text, gut verlinkt, kein Login,
# wenig JavaScript), Schwerpunkt deutschsprachig. Soziale Netzwerke, Shops und
# Video-Plattformen fehlen bewusst: Sie sperren Crawler oder liefern ohne
# Browser kaum Text.
#
# Wayon beachtet robots.txt automatisch. Seiten, die fremde Crawler verbieten,
# werden übersprungen.
#
# Verwendung:
#   wayon crawl --seeds-file seeds/top100.txt --stay-on-domains \
#               --max-per-host 2000 --max-pages 200000 --concurrency 100
#
# Zeilen mit # sind Kommentare.
